# Goal Tracker

Goal tracker with progress bars and milestone checklists.

## Features
- Create goals with target %
- Milestone toggles drive progress
- Archive completed goals

## Limitations
- Local only
- Progress is milestone-based (equal weight)

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- localStorage persistence

## Run
```bash
npm install
npm run dev
```

## Honesty notes
- Portfolio mini-app showcase
- Not multi-tenant SaaS
